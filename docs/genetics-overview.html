01 / Where it lives

Three layers.
One breeding path.

The pure model stays reusable and NMS-free. The server façade attaches genomes to entities. Thin vanilla hooks call into it at the moments Minecraft already understands.

API

Pure genetics core

Models genomes and loci, chooses gametes, crosses chromosomes, mutates DNA, and decodes phenotypes without Minecraft classes.

alkahest-api/src/main/java/dev/mintychochip/genetics/
NMS

Server entity bridge

Caches genomes by UUID, persists them as MintyGenome, applies phenotypes, gates mates, and prepares child metadata.

Vanilla touchpoints
